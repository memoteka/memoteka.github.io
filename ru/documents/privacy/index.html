Политика конфиденциальности

Дата вступления в силу: 28 апреля 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — Политика) описывает, какие данные собирает и обрабатывает сайт «Мемотека» (далее — Сайт), а также цели их использования.

2. Какие данные собираются

  • Данные, предоставленные пользователем: при оформлении доната вы можете указать имя, сумму и сообщение. Эти данные передаются платёжной системе ЮMoney и не хранятся на Сайте.
  • Технические данные: Сайт может собирать обезличенную информацию о браузере, IP-адресе, типе устройства через стандартные логи сервера GitHub Pages (хостинг не передаёт эти данные нам).
  • Локальное хранилище: Сайт использует localStorage для сохранения выбранной темы и языка. Эти данные не покидают ваш браузер.
  • Файлы cookie: Сайт не использует сторонние файлы cookie для отслеживания.

3. Использование данных

Собранные данные используются исключительно для:

  • обеспечения работы функционала Сайта (темы, язык);
  • обработки донатов через платёжную систему ЮMoney;
  • улучшения пользовательского опыта (анализ производительности, исправление ошибок).

4. Передача данных третьим лицам

Данные пользователей не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ. При совершении доната информация передаётся платёжной системе ЮMoney в соответствии с её политикой конфиденциальности.

5. Хранение и защита данных

Все данные хранятся локально в вашем браузере или временно обрабатываются серверами GitHub Pages и ЮMoney. Мы принимаем разумные меры для защиты данных от несанкционированного доступа.

6. Права пользователя

Вы можете в любой момент очистить localStorage вашего браузера, что удалит сохранённые настройки темы и языка. Для удаления других данных обратитесь к настройкам вашего браузера или свяжитесь с нами.

7. Изменения в Политике

Мы оставляем право обновлять данную Политику. Изменения публикуются на этой странице с указанием новой даты вступления в силу.

8. Контакты

По вопросам, связанным с обработкой данных, вы можете связаться через Telegram: @normik_chel или VK: vk.com/normik_chel.
